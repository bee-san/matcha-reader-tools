# PP-OCRv6_manga

`manga_det_v0.2_fp16.onnx`, `manga_rec_v0.2_fp16.onnx` and `ppocrv6_dict.txt` are unmodified
files from [Kellenok/PP-OCRv6_manga](https://huggingface.co/Kellenok/PP-OCRv6_manga) (v0.2),
licensed under the Apache License 2.0. They are PaddlePaddle's PP-OCRv6 tiny detector and small
recogniser, fine-tuned on manga and anime text (Japanese and Chinese). `js/ppocr.js` runs them.
